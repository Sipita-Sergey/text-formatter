# text-formatter («форматёр»)

Скармливаешь ему расшифровку созвона, статью или длинный документ. На выходе тот же текст, но
читаемый: разбит на абзацы, с заголовками и коротким блоком «о чём этот файл» в начале. Ничего
не пересказывается и не сокращается, убираются только слова-паразиты, а ошибки распознавания речи
(«code kwork» вместо «Claude Cowork») чинятся.

Зачем это нужно, если текст и так есть. Нейронка работает с таким файлом заметно быстрее и
дешевле: по заголовкам и блоку в начале она сразу понимает, что внутри, и находит нужное, не
читая всё подряд. Особенно заметно, когда документов много и они большие.

Внутри есть обязательная проверка на потери: небольшой скрипт сравнивает исходник и результат и
показывает слова, которые пропали. Агент, который сам себя проверяет, пропускает ровно то, что
пропустил при записи; скрипт нет.

Работает с `.md` и `.txt`, понимает метки «Спикер 1 / Спикер 2» из расшифровок
[transcribe-batch](https://github.com/leonovs0808-star/transcribe-batch) и не склеивает реплики
разных людей.

Сделал [Сергей Сипита](https://t.me/SipitaSergey) — про ИИ в работе и нейроофисы пишу в канале
[@sipita08](https://t.me/sipita08).

## Не программист? Пусть поставит ИИ

Не открывай эту страницу руками — отправь **вот эту ссылку**:

> https://raw.githubusercontent.com/leonovs0808-star/text-formatter/master/INSTALL-FOR-AI.md

в чат с Claude, ChatGPT или Codex **на том же компьютере**, где будешь пользоваться (нужен
доступ к файлам — на телефоне и в браузере это не сработает), и напиши:
**«установи мне это по этой инструкции»**. Дальше ИИ всё сделает сам: положит папку в «Документы» и
покажет работу на примере.

Ключей и регистраций не нужно: форматёр работает прямо в чате.

## Установка руками

Форматёр — обычная папка с файлом `AGENTS.md`. Его читают Claude, Codex, Cursor и другие агенты,
когда открыты в этой папке. Поэтому не важно, какая у тебя нейронка.

```bash
git clone https://github.com/leonovs0808-star/text-formatter.git ~/Documents/text-formatter
```

Дальше открой эту папку в своей нейронке, положи в неё файл с текстом и напиши: «отформатируй
расшифровку такую-то». Результат появится рядом с исходником под именем `<имя>_formatted.md`.

Файл лежит в другом месте? Напиши в любом чате: «Прочитай `<путь к папке>/AGENTS.md` и
отформатируй по нему файл <путь к файлу>».

Хочешь вызывать форматёр из любого чата без открытия папки: скопируй её в папку навыков своего
агента (`~/.claude/skills/text-formatter` для Claude Code, `~/.codex/skills/text-formatter` для
Codex). Тонкий `SKILL.md` внутри отправит агента читать `AGENTS.md`.

## Как устроен

| Файл | Что делает |
|---|---|
| `AGENTS.md` | Главная инструкция: как получить текст, куда сохранить, как проверить потери. Её читает любой агент |
| `SKILL.md`, `CLAUDE.md` | Тонкие оболочки: отправляют агента читать `AGENTS.md` |
| `INSTALL-FOR-AI.md` | Инструкция для нейронки, которая ставит форматёр за тебя |
| `steps/01-format.md` | Правила форматирования: что нельзя, что можно убрать, как ставить заголовки |
| `tools/check-losses.py` | Сверка исходника и результата по словам, нужен только Python |
| `examples/example.md` | Короткий пример для первой проверки |
