# Инструкция для ИИ-агента: установить форматёр

Ты помогаешь пользователю поставить **форматёр** — набор правил, который превращает сырую
расшифровку, документ или статью в аккуратный markdown: абзацы, заголовки, контекстный блок в
начале. Текст при этом не пересказывается и не сокращается, убираются только слова-паразиты и
чинятся ошибки распознавания речи. Пользователь, скорее всего, не программист: веди его без
жаргона и говори, что именно происходит.

**Цель установки:** форматёр доступен пользователю там, где он с тобой разговаривает, проверен на
примере, и пользователь знает одну фразу, после которой текст форматируется.

## Шаг 0. Выбери путь по тому, что ты умеешь, а не по своему названию

Где пользователь и какая у него нейронка, **не спрашивай**: ты видишь это по себе. Выбери один путь
и в ответе давай только его, остальные пользователю не пересказывай и другие нейронки не
перечисляй.

- **Путь А — у тебя есть терминал или доступ к файлам компьютера** (Claude Code, Claude в
  приложении с доступом к папкам, Codex, Cursor и подобные). Ставишь сам: разделы «Железные
  правила» и шаги 0а–4 ниже.
- **Путь Б — терминала нет, и ты Claude** (claude.ai в браузере, приложение без доступа к
  файлам). Скилл ставится через раздел «Навыки» — раздел «Путь Б» ниже.
- **Путь В — терминала нет, и ты ChatGPT** (chatgpt.com в браузере, приложение). Есть ли
  у пользователя раздел «Навыки», ты не видишь и **не спрашиваешь** — вопрос без файла оставляет
  его ни с чем. В первом же ответе дай оба варианта сразу, каждый со своими шагами: «Если в меню
  слева „Плагины“ есть вкладка „Навыки“ — …» (раздел «Путь Б») и «Если нет — …» (раздел «Путь В:
  проект»). Архив в обоих случаях один и тот же — ссылку дай один раз.
- **Путь Г — любая другая нейронка** (DeepSeek, Gemini, GigaChat, Алиса, Qwen, Grok, Perplexity и
  любая, которой нет в этом списке) **или ты не уверен, кто ты.** Раздел «Путь Г: один файл».
  Он работает в любой нейронке, где к сообщению можно прикрепить файл: «Навыки» для него не нужны.

Не знаешь точно, есть ли у тебя терминал, — попробуй выполнить простую команду. Не вышло — у тебя
его нет. Не знаешь точно, Claude ты или ChatGPT, — иди «Путём Г».

## Путь Г: один файл (любая нейронка)

Весь форматёр — один текстовый файл с правилами. Нейронка, которой этот файл прикрепили к
сообщению, форматирует по нему. Архив zip на этом пути не давай: не каждая нейронка его открывает.

Ответь пользователю одним коротким сообщением, ровно этими тремя шагами:

1. Скачать форматёр одним файлом: https://github.com/Sipita-Sergey/text-formatter/releases/download/latest/text-formatter.md
2. Открыть новый чат, прикрепить этот файл и текст, который нужно отформатировать (файлом или
   вставить в сообщение), и написать: «отформатируй по правилам из файла».
3. Отформатированный текст придёт в чат. В следующий раз — так же: файл форматёра и текст.

Ссылку пиши полным адресом, как здесь, чтобы она была кликабельной. **Ответ без ссылки — провал
установки.** Названий меню своей нейронки не придумывай: если у тебя есть место для постоянных
файлов или инструкций и ты **точно** знаешь, как оно называется, можешь одной строкой добавить,
что файл можно положить туда один раз. Не знаешь точно — не пиши.

## Путь Б: раздел «Навыки» (Claude или ChatGPT без терминала)

Умеешь скачать файл по ссылке и отдать его пользователю файлом в чате (Claude с выполнением кода это
умеет) — скачай архив, проверь, что внутри папка `text-formatter` с `SKILL.md`, и отдай файлом. Не
умеешь — дай ссылку. **Ответ без файла и без ссылки — провал установки:** ссылку пиши полным
адресом, как в этой инструкции, чтобы она была кликабельной, — по клику браузер скачает сам.

1. Скачать скилл одним архивом: https://github.com/Sipita-Sergey/text-formatter/releases/download/latest/text-formatter.zip
   Архив не распаковывать.
2. **Claude:** «Настройки» → «Возможности» (Capabilities) → включить «Выполнение кода и создание
   файлов» (Code execution and file creation). Без этого навыки не работают. Затем «Настроить»
   (Customize) → «Навыки» (Skills) → «+» → «Создать навык» → «Загрузить навык» → выбрать скачанный
   архив.
   **ChatGPT:** «Плагины» в меню слева → вкладка «Навыки» → «+» → загрузить скачанный архив
   целиком. Навыки в браузере, в приложении и на телефоне не синхронизируются: ставить там, где
   пользователь работает.
3. Новый чат → прислать любой текст и написать «отформатируй». Для проверки — прислать пример
   отсюда: https://raw.githubusercontent.com/Sipita-Sergey/text-formatter/master/examples/example.md

Не нашёл пользователь нужный пункт меню — не придумывай названия, попроси скриншот и веди по
тому, что на нём видно. Раздела «Навыки» у него нет вовсе — в ChatGPT переходи на «Путь В: проект»,
в Claude — на «Путь Г: один файл».

## Путь В: проект (раздела «Навыки» нет)

Форматёр кладётся в проект тем же архивом, что и для «Навыков». Каждый новый чат внутри проекта
работает по нему: нейронка сама открывает архив и читает инструкции.

1. Скачать форматёр одним архивом (тот же, что в «Пути Б»): https://github.com/Sipita-Sergey/text-formatter/releases/download/latest/text-formatter.zip
   Архив не распаковывать.
2. Создать проект: в ChatGPT — «Проекты» → «Новый проект». Название любое, например «Форматёр».
3. В файлы (источники) проекта загрузить скачанный архив.
4. В инструкцию проекта вставить одну строку:
   «Когда я прошу отформатировать текст, открой архив text-formatter.zip из файлов проекта и
   работай строго по AGENTS.md и steps/01-format.md из него».
5. Открыть новый чат внутри этого проекта, прислать текст и написать «отформатируй».

Предупреди одной фразой: так форматёр работает только внутри этого проекта.

## Путь А: установка на компьютер

**Как это устроено.** Форматёр — обычная папка с файлом `AGENTS.md`. Его читают Claude, Codex,
Cursor и другие агенты, когда открыты в этой папке. Поэтому не важно, какая у пользователя
нейронка: папка кладётся на компьютер один раз, а дальше любой агент, открытый в ней, умеет
форматировать. Папки навыков и настройки агента для этого не нужны.

## Железные правила

- Настройки компьютера пользователя не трогай: VPN, прокси, файрвол, системную сеть. Установка
  их не требует.
- Файлы пользователя никуда не отправляй. Форматёр работает прямо в этом чате и на этом
  компьютере, внешних сервисов ему не нужно.
- Ключей и регистраций не нужно вообще. Если ты начал просить у пользователя ключ или аккаунт,
  ты что-то перепутал.

## Шаг 0а. Убедись, что вы на одной машине

Папка ставится туда, где ты выполняешь команды. Если ты работаешь на удалённом сервере, в
контейнере или в WSL, а человек сидит за своим Маком или Windows, это разные компьютеры, и
форматёр встанет не туда, где лежат его тексты. Если файл пользователя уже виден тебе (лежит в
текущей папке или он назвал путь, и ты его открыл), вопрос не нужен. Иначе спроси по-человечески,
без слов «сервер» и «контейнер»: «Назови любую папку с твоими текстами, проверю, вижу ли я её».
Не нашёл папку, которую он назвал, скажи прямо: «я работаю не на твоём компьютере, твоих файлов
отсюда не видно», и разберитесь, куда ставить. Молча ставить «куда получится» нельзя.

Доступа к терминалу или файлам нет — ты не на этом пути: вернись к шагу 0 и иди «Путём Б», «Путём В» или «Путём Г».

## Шаг 1. Выбери папку

Систему определи сам (`python3 -m platform`, в Windows команда `python`, или `uname -s`), у
пользователя не спрашивай. Дальше выдавай только то, что подходит этой системе.

Папка форматёра по умолчанию называется `text-formatter` и лежит в «Документах» пользователя
(`~/Documents/text-formatter`; в Windows `$env:USERPROFILE\Documents\text-formatter`). Другое
место выбирай, только если пользователь сам назвал его. Путь покажи пользователю: ему придётся
открывать эту папку.

## Шаг 2. Скачай

Репозиторий: https://github.com/Sipita-Sergey/text-formatter

Если есть `git`:

```bash
git clone https://github.com/Sipita-Sergey/text-formatter.git <папка из шага 1>
```

Нет `git` — скачай архив https://github.com/Sipita-Sergey/text-formatter/archive/refs/heads/master.zip
и распакуй так, чтобы `AGENTS.md` лежал прямо внутри папки `text-formatter`, а не внутри
вложенной `text-formatter-master`.

Грабли, на которых спотыкаются чаще всего:

- **Папка уже существует.** Не клонируй поверх. Если там репозиторий, сделай `git pull`. Если
  там что-то другое, спроси пользователя, прежде чем трогать.
- **Вложенная папка.** Проверь, что файл лежит ровно по пути `<папка форматёра>/AGENTS.md`, а не
  `.../text-formatter/text-formatter/AGENTS.md`.
- **Составные команды.** В песочницах агентов команды с `cd` и `&&` часто блокируются. Давай
  полные пути и по одной команде.
- **Окно с вопросом о разрешении.** Запись вне рабочей папки может вызвать запрос подтверждения.
  Перед действием предупреди пользователя одной фразой: «сейчас появится окно с вопросом, нажми
  разрешить». Отказали или подтвердить некому: остановись и объясни, что нужно разрешить. Защиту
  и песочницу не обходи.
- **`git` просит установить инструменты разработчика** (так бывает на Mac). Не запускай установку
  молча: скажи, что это займёт несколько минут и нужно один раз, либо возьми архив без `git`.
- **Windows.** Домашняя папка там `$env:USERPROFILE`, а `~` в некоторых оболочках не раскрывается.
  Раскрой путь сам, не вставляй `~` в команды PowerShell вслепую.

## Шаг 3. Проверь, что работает

В папке лежит короткий пример `examples/example.md`: кусок разговора двух людей с паразитами и
ошибками распознавания. Файла `examples/example_formatted.md` там нет, ты создаёшь его сам:
отформатируй `example.md` по `AGENTS.md` и `steps/01-format.md`, сохрани рядом под именем
`example_formatted.md` и покажи пользователю результат.

Потом проверь потери полным путём к скрипту:
`python3 <папка форматёра>/tools/check-losses.py <папка форматёра>/examples/example_formatted.md`
(в Windows `python`). Если Python на компьютере нет, не ставь его без спроса. Форматёр работает и
без него, а сверку тогда делаешь вручную по разделу «Верификация» шага `steps/01-format.md`.
Скажи об этом пользователю одной фразой.

Скажи пользователю по итогам проверки одной фразой, а не выводом скрипта. Например: «Скрипт
показал два слова, это были рекламная вставка про подписку, её убирать можно, остальное на месте».
Слово, которое ты убрал зря, верни в текст.

Удалять `example_formatted.md` не нужно, но и считать его результатом пользователя нельзя.

## Шаг 4. Скажи пользователю, как пользоваться

Коротко, четыре строки (подставь реальный путь папки):

1. Форматёр лежит в папке `<путь>`.
2. Открой эту папку в своей нейронке (в Claude, Codex, Cursor или другой), положи туда файл с
   текстом и напиши: «отформатируй расшифровку такую-то». Нейронка сама прочтёт `AGENTS.md`.
3. Файл лежит в другом месте? Напиши в любом чате: «Прочитай `<путь>/AGENTS.md` и отформатируй
   по нему файл <путь к файлу>».
4. Рядом с исходником появится файл с таким же именем и добавкой `_formatted`. Исходник не
   изменится.

### По желанию: чтобы работало в любом чате без открытия папки

Если у агента есть своя папка навыков и пользователь хочет вызывать форматёр из любого чата, положи
или скопируй папку форматёра в папку навыков агента (для Claude Code `~/.claude/skills/text-formatter`,
для Codex `~/.codex/skills/text-formatter`). Тонкий `SKILL.md` внутри отправит агента читать
`AGENTS.md`. Это необязательно: без этого форматёр работает так, как описано выше.

Не рассказывай пользователю про устройство репозитория. Ему нужно знать, как отформатировать
свой первый файл.
